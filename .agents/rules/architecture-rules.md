# دليل المعمارية وتصميم النظم لبرنامج NeprasPro

## 1. بنية التطبيق (Offline-First Stack)
* **Electron**: الغلاف الرئيسي للتشغيل محلياً على أجهزة المدارس بدون الحاجة لإنترنت.
* **React**: الفرونت إند لبناء واجهات تفاعلية وسريعة.
* **SQLite3**: قاعدة البيانات المحلية وتعمل من مسار التخزين الخاص بالمستخدم `%USERPROFILE%/.nepraspro/nepraspro.db`.

## 2. قواعد البيانات والترقيات التراكمية
* يمنع منعاً باتاً إنشاء قاعدة البيانات في مجلد تثبيت التطبيق (`Program Files` أو مجلد المشروع).
* عند كتابة أي `Migration` لتطوير الجداول:
  ```sql
  CREATE TABLE IF NOT EXISTS example_table (...);
  ```
  أو استخدام `PRAGMA table_info` للتحقق من وجود الأعمدة قبل إضافتها `ALTER TABLE`.

## 3. قواعد تصميم الواجهات (EMIS Design System)
* **Cairo Font**: يُدرج خط القاهرة كخط افتراضي أساسي للنظام.
* **Colors Palette**:
  * Primary / Header: `#1a3c6e` (أزرق حكومي)
  * Background: `#f0f2f5` (رمادي هادئ)
  * Surface Card: `#ffffff` (أبيض ناصع)
  * Accent / Active: `#2563eb` / `#1d4ed8`
  * Success: `#16a34a` | Warning: `#d97706` | Danger: `#dc2626`
* **Micro-interactions**: أزرار الاستجابة، التأثيرات التفاعلية السلسة عند الفرز والتصفية.

## 4. ضوابط المعالجة والتحقق
* فحص وتدقيق الرقم القومي للطلاب (14 رقم ميلادي دقيق).
* منع خلط الأكواد مع النصوص العربية في عمليات الربط والـ Queries.
* إدراج التقييمات والضوابط التأسيسية بناءً على مدخلات المصمم/المستخدم عند الطلب.
