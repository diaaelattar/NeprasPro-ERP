## 💻 1. متطلبات التشغيل والمواصفات (System Requirements)

تم تصميم المنظومة للعمل بكفاءة فائقة وسرعة استجابة على أجهزة المدارس والمكاتب بكافة أنواعها:

* **نظام التشغيل:** Windows 7 / Windows 8 / Windows 10 / Windows 11 (32-bit أو 64-bit).
* **الذاكرة العشوائية (RAM):** 2 جيجابايت (حد أدنى) — 4 جيجابايت فما فوق (مستحسن).
* **المعالج (CPU):** Intel Celeron / Core i3 أو أي معالج متوافق.
* **المساحة المتاحة علي القرص:** 300 ميجابايت فقط.
* **الشاشة والدقة:** تدعم جميع الشاشات بدءاً من دقة `1024x768` و `1366x768` فما فوق.
* **البرامج المساعدة:** لا تتطلب أي متطلبات تعجيزية أو محركات قواعد بيانات خارجية؛ المنظومة تعمل ذاتياً ومدمج معها كافة المحركات.

## 📦 2. تعليمات التثبيت والترقية التراكمية (Setup Instructions)

1. اضغط مرتين على ملف التثبيت المرفق: **`NeprasPro Setup 1.1.0.exe`**.
2. اتبع خطوات التثبيت واضغط على **"التالي (Next)"** ثم **"تثبيت (Install)"**.
3. **التحديث التراكمي المباشر (Setup over Setup):** 
   - عند إصدار أي تحديث جديد من المطور، يتم تثبيت ملف `Setup` الجديد مباشرة فوق القديم دون الحاجة لإلغاء التثبيت.
   - البنية المعمارية للمنظومة تحفظ بيانات المدرسة والطلاب والتكويدات في المجلد الآمن للمستخدم (`%USERPROFILE%/.nepraspro/`) وبالتالي لا تضيع البيانات مطلقاً عند التحديث أو الترقية.
